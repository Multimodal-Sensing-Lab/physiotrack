MPEBlink 2.0 Eye Openness and Blink Validation
================================================

Overview
--------
This validation evaluates the PhysioTrack EyeOpenness descriptor and
threshold-based blink detector on the MPEBlink 2.0 benchmark.

Two complementary benchmark aspects are assessed:

1. Eye-openness discrimination between blink and non-blink frames.
2. Temporal blink-event detection, including event detection accuracy,
   temporal overlap, blink count, blink rate, and duration error.

The evaluation uses the MPEBlink 2.0 validation split for parameter selection
and the official test split for final quantitative and qualitative evaluation.
Independent software-level FaceAnalysis execution and a separately annotated
five-video synthetic demonstration provide additional, non-benchmark evidence.

Evaluated PhysioTrack Components
--------------------------------
Face landmarks:

PhysioTrack FaceLandmarks using MediaPipe Face Landmarker.

Eye openness:

PhysioTrack EyeOpenness using mean_openness.

Blink detection:

PhysioTrack BlinkDetector using a fixed EyeOpenness threshold and a minimum
number of consecutive closed frames.

Face Initialization
-------------------
The MPEBlink 2.0 ground-truth face bounding box for each annotated person is
used to initialize FaceLandmarks.

This protocol isolates EyeOpenness and blink detection from face-detection
errors. Missing or invalid boxes and landmark failures are recorded explicitly.

EyeOpenness Geometry
--------------------
EyeOpenness is computed from facial landmarks in pixel-consistent geometry.

For two landmarks p1 and p2:

    dx = (p1.x - p2.x) * image_width
    dy = (p1.y - p2.y) * image_height

    distance = sqrt(dx^2 + dy^2)

The eye-openness ratio is then calculated from the relevant horizontal and
vertical eye landmark distances.

BlinkDetector elapsed-time accounting
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
In the FaceAnalysis video pipeline, BlinkDetector uses the zero-based video
frame index, including elapsed frames during which a tracked person is absent.
For a person first observed in frame i_first and currently at frame i_current:

    elapsed_frames = i_current - i_first + 1
    elapsed_seconds = elapsed_frames / video_fps
    blink_rate_per_min = 60 * blink_count / elapsed_seconds

BlinkDetector.update() also accepts a standalone sequence without frame_index.
In this mode, consecutive calls for a person represent consecutive frames.

An explicit gap in frame indices breaks an incomplete eye-closure sequence,
while the cumulative blink count is retained. FaceAnalysis resets the video
clock and temporal states when reset_temporal_state() is called between videos.

Successive FaceAnalysis.predict() calls are assumed to represent consecutive
input video frames. The internal clock cannot infer source frames that callers
skip entirely.

The isolated component validation independently checks each stored per-person
blink_rate against the elapsed frame span and measured video FPS. Scientific
MPEBlink benchmark blink-rate MAE uses complete annotated person-sequence
frames and is a separate evaluation metric.

Synthetic Qualitative and Accuracy Demonstration
------------------------------------------------
Purpose and separation
~~~~~~~~~~~~~~~~~~~~~~
The independent synthetic test is performed on computer-generated videos,
not on the MPEBlink 2.0 benchmark. Unlike benchmark evaluation with controlled
per-person ground-truth face boxes, the synthetic workflow uses the real
Face detector followed by FaceTracker (OC-SORT), MediaPipe FaceLandmarks,
EyeOpenness, and BlinkDetector within PhysioTrack FaceAnalysis. The detector
and tracker thus remain part of the synthetic end-to-end execution path.
Unrelated FaceAnalysis modules are disabled.

The EyeOpenness calculation and native blink-state updates are not replaced
by demonstration logic. The eye-region points shown in the video are the
actual landmarks passed to EyeOpenness; the point radius of one pixel is a
drawing setting only. A fresh tracker and blink temporal state are used for
each video. Detector confidence is 0.25, detector IoU is 0.45, and processing
is performed on CPU. Blink threshold 0.22 and min_closed_frames 3 are the
fixed settings selected on the MPEBlink validation split, not retuned on
synthetic test videos.

Method and event scoring
~~~~~~~~~~~~~~~~~~~~~~~~
The default command runs the whole synthetic workflow, rather than requiring
separate inference and scoring commands:

python eye_blink_synthetic_demo.py

The script validates the video files and reviewed ground-truth annotations,
processes all frames with the real FaceAnalysis pipeline, writes the
qualitative annotations and per-person frame observations, then derives
predicted blink intervals from actual BlinkDetector pulses in those
observations. It evaluates the events against independently reviewed GT blink
intervals using one-to-one greedy matching at temporal IoU >= 0.50.
Predicted event intervals are measured in closed-eye frames; the GT labels
cover visually observed blink motion. Partial temporal disagreement can
therefore reduce matched tIoU, even when an event is detected.

The synthetic metrics use micro-aggregated event counts over all annotated
persons and videos. Precision = TP/(TP + FP); Recall = TP/(TP + FN);
F1 = 2PR/(P + R). A zero denominator is reported as 0.0 by this script,
with event counts retained for interpretation. Prolonged closures are
annotated separately, are not treated as GT blink events, and a model pulse
on a prolonged closure is counted as an FP unless it independently matches
a GT blink event.

The optional command --evaluate-only recomputes the synthetic accuracy and
GT overlays from previously saved synthetic_demo observations without
rerunning the detector or MediaPipe. The optional --make-gt-template command
creates empty, unreviewed GT fields when no annotation file exists; an empty
template cannot be used as ground truth. These modes are not required for the
standard one-command complete reproduction.

The program verifies that implementation classes come from the local
physiotrack-v2 source checkout and records Python, OpenCV, NumPy, and other
package versions, plus hashes of the demonstration script and core source
modules.
The recorded completed run used Windows, Python 3.11.17, OpenCV 5.0.0,
NumPy 2.4.6, MediaPipe 1.1.0, and Ultralytics 8.4.177 on CPU. Source-video SHA-256 hashes are preserved in the qualitative
summary, and the independently annotated GT file hash is recorded in the
accuracy summary. Equivalent model predictions also depend on using the
same pretrained model weights, source files, dependency versions, and
compatible runtime; universal bitwise-identical outputs on any device are
not guaranteed.

The two script-owned folders, synthetic_demo and synthetic_demo_accuracy,
are prepared in temporary staging locations. During a standard full run,
all videos and tables are produced and validated before either accepted
output folder is replaced. The publication step installs both new folders
without merging old files and checks the published outputs. An ordinary
publication failure triggers restoration of the previous folders. After
normal successful publication, temporary staging data and previous-output
backups are cleaned. The two folders do not replace any benchmark,
qualitative benchmark, or isolated-component artifacts.

The synthetic set is small and artificial. Its manually annotated event F1
of 88.89% describes only these five rendered videos, not real-world
sensitivity or a replacement for the 28.62% MPEBlink test F1 under its
separate controlled face-initialization protocol. Short blinks and prolonged
closures demonstrate genuine limitations of the fixed-threshold rule.

Interpretation
--------------
PhysioTrack EyeOpenness provides moderate discrimination between blink and
non-blink frames on MPEBlink 2.0. Blink frames show lower EyeOpenness values
than non-blink frames, with a ROC AUC of 0.660775.

The threshold-based temporal blink detector reaches 32.40% precision, 25.63%
recall, and 28.62% F1. Matched blink events have a mean temporal IoU of
0.671862.

The difference between frame-level EyeOpenness discrimination and event-level
blink detection indicates that a simple fixed-threshold temporal rule remains
limited under unconstrained multi-person video conditions.

Evaluation Scope
----------------
This benchmark evaluates EyeOpenness and threshold-based blink detection under
ground-truth face initialization.

It does not evaluate face detection.

It does not train or fine-tune a blink-specific model.

The reported blink-event metrics follow the project protocol based on
one-to-one temporal-IoU matching at tIoU >= 0.50.

The isolated component execution uses the same benchmark test population and
controlled face initialization only to verify execution of the
PhysioTrack EyeOpenness and BlinkDetector components. It does not generate a
new set of benchmark accuracy claims.
