MPEBlink 2.0 Eye Openness and Blink Validation
================================================

Overview
--------
This validation evaluates the PhysioTrack EyeOpenness descriptor and
threshold-based blink detector on the MPEBlink 2.0 benchmark.

Two complementary aspects are assessed:

1. Eye-openness discrimination between blink and non-blink frames.
2. Temporal blink-event detection, including event detection accuracy,
   temporal overlap, blink count, blink rate, and duration error.

The evaluation uses the MPEBlink 2.0 validation split for parameter selection
and the official test split for final quantitative and qualitative evaluation.

Validation Package
------------------
Location:

physiotrack/validation/eye_openness_and_blink/

Main scripts:

mpeblink_blink_eval.py
    Performs dataset preflight checks, validation-split parameter calibration,
    final test evaluation, event-level metric computation, EyeOpenness
    analysis, and generation of evaluator-owned quantitative results.

mpeblink_blink_plot.py
    Independently verifies the accepted test summary against the per-sequence
    results, generates the thesis-ready CSV and Markdown tables, creates the
    final test-performance figure, and visualizes the validation calibration
    F1 curves from the stored calibration CSV.

mpeblink_blink_qualitative.py
    Generates deterministic qualitative benchmark examples from the final
    test results. Selected sequences are re-evaluated using the same protocol
    and checked against the quantitative sequence-level results before visual
    outputs are produced. The visualizations display only the eye-region
    landmarks used by EyeOpenness to keep the evidence focused on the
    evaluated component.

Evaluated PhysioTrack Components
--------------------------------
Face landmarks:
PhysioTrack FaceLandmarks using MediaPipe Face Landmarker.

Eye openness:
PhysioTrack EyeOpenness using mean_openness.

Blink detection:
PhysioTrack BlinkDetector using a fixed EyeOpenness threshold and a minimum
number of consecutive closed frames.

Face Initialization
-------------------
The MPEBlink 2.0 ground-truth face bounding box for each annotated person is
used to initialize FaceLandmarks.

This protocol isolates EyeOpenness and blink detection from face-detection
errors. Missing or invalid boxes and landmark failures are recorded explicitly.

EyeOpenness Geometry
--------------------
EyeOpenness is computed from facial landmarks in pixel-consistent geometry.

For two landmarks p1 and p2:

    dx = (p1.x - p2.x) * image_width
    dy = (p1.y - p2.y) * image_height

    distance = sqrt(dx^2 + dy^2)

The eye-openness ratio is then calculated from the relevant horizontal and
vertical eye landmark distances.

Parameter Selection
-------------------
The validation split is used for blink-parameter selection.

Calibration search:

Blink threshold:
0.10 to 0.50 in increments of 0.01

Minimum consecutive closed frames:
1, 2, 3, 4

Event matching criterion:
temporal IoU >= 0.50

Selected configuration:

blink_threshold = 0.22
min_closed_frames = 3

Validation performance at the selected configuration:

Precision:
0.259956

Recall:
0.251203

F1:
0.255504

The selected configuration is fixed before final evaluation on the test split.

The plotting script also verifies that the selected configuration exists in
results/mpeblink_val_calibration.csv and that its F1 equals the maximum F1
recorded in that calibration file before generating the calibration figure.

The validation-calibration figure reports blink-event F1 across the tested
EyeOpenness thresholds for min_closed_frames values 1, 2, 3, and 4. It is a
parameter-selection visualization, not a ROC curve.

Metrics
-------
Blink-event precision:

                  TP
    Precision = --------
                TP + FP

Blink-event recall:

               TP
    Recall = --------
             TP + FN

Blink-event F1:

             2 * Precision * Recall
    F1 = --------------------------------
              Precision + Recall

Temporal intersection over union:

                  temporal intersection
    tIoU = -----------------------------------
                   temporal union

Additional event metrics:

- Mean matched temporal IoU
- Median matched temporal IoU
- Mean onset error in frames
- Mean offset error in frames
- Mean blink-duration error in seconds
- Blink-count MAE per person sequence
- Blink-rate MAE in blinks per minute

Eye-openness metrics:

- EyeOpenness availability
- Blink-frame EyeOpenness mean and median
- Non-blink EyeOpenness mean and median
- ROC AUC using negative EyeOpenness as the blink score

Interpretation
--------------
PhysioTrack EyeOpenness provides moderate discrimination between blink and
non-blink frames on MPEBlink 2.0. Blink frames show lower EyeOpenness values
than non-blink frames, with a ROC AUC of 0.660808.

The threshold-based temporal blink detector reaches 32.42% precision, 25.66%
recall, and 28.65% F1. Matched blink events have a mean temporal IoU of
0.671718.

The difference between frame-level EyeOpenness discrimination and event-level
blink detection indicates that a simple fixed-threshold temporal rule remains
limited under unconstrained multi-person video conditions.

Evaluation Scope
----------------
This benchmark evaluates EyeOpenness and threshold-based blink detection under
ground-truth face initialization.

It does not evaluate face detection.

It does not train or fine-tune a blink-specific model.

The reported blink-event metrics follow the project protocol based on
one-to-one temporal-IoU matching at tIoU >= 0.50.
